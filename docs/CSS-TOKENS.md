# Локальные CSS-токены (ветка `refactor/local-css-tokens`)

## Идея

Бренд-токены живут в `:root` (`--brand-*`).
Семантические токены (`--bg`, `--accent`, …) переназначаются в scope компонента:

| Класс | Назначение |
|---|---|
| `.theme` | Базовая тёмная тема (дефолт) |
| `.theme--elevated` | Приподнятый фон секции |
| `.theme--band` | Жёлтая полоса (услуги / CTA) |
| `.theme--panel` | Изолированная тёмная карточка внутри band |

Tailwind-утилиты (`bg-bg`, `text-accent`, …) читают `var(--bg)` / `var(--accent)` через `@theme inline`, поэтому вложенный `.theme--panel` не ломает родителей и наоборот.

## Сравнение с `main`

| | `main` | эта ветка |
|---|---:|---:|
| CSS bundle | ~32.9 KB | ~34.5 KB (+~1.5 KB) |
| Страниц | 20 | 20 |
| Build | ~300 ms | ~220–360 ms |

Разница в CSS — из описания theme-скоупов. На FPS/LCP это обычно незаметно: переменные резолвятся при cascade.

## Как смотреть

```bash
npm run dev
```

Главная: жёлтый блок услуг + CTA должны выглядеть как раньше, карточки внутри — тёмные за счёт `.theme--panel`.
