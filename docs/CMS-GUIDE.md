# Инструкция для редактора — REAL CONSTRUCTION CO (Strapi)

## Вход

1. Откройте адрес админки (например `https://cms.realconstruction.kz/admin`).
2. Войдите под учётной записью **Editor** или **Administrator**.

## Что можно редактировать

| Раздел | Для чего |
|---|---|
| **Service** | Услуги компании (название, описание, особенности, иконка) |
| **Project** | Проекты / портфолио (фото, категория) |
| **Partner** | Клиенты и партнёры (название, логотип) |
| **Certificate** | Сертификаты и лицензия (код, PDF) |

## Языки

Для записей с переводом (i18n) переключайте язык в правом верхнем углу карточки: **ru / en / kk**.

## Публикация

1. Заполните поля.
2. Нажмите **Save**.
3. Нажмите **Publish**.
4. После публикации фронтенд обновляется при следующей сборке сайта (или автоматически, если настроен webhook).

## Медиа

Загружайте логотипы и PDF через **Media Library**. Используйте WebP/JPEG для фото, PDF для сертификатов.

## Права

- **Administrator** — полный доступ, настройки, пользователи.
- **Editor** — только контент (услуги, проекты, партнёры, сертификаты).

## Поддержка

При ошибках входа или публикации обратитесь к разработчику сайта.
